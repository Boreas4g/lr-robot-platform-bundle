## 使用与核验

- 使用地图时，将 `map.yaml` 与 `map.pgm` 放在同一目录，保留两者的文件名关系。
- `标注点.yaml` 是本次备份的数据文件，不是 Nav2 地图 YAML，也不保证可直接作为现有程序的点位导入文件；恢复时需根据标注记录重建地图点位，并保持图书与点位关联正确。
- 如使用平台已有的图书批量导入功能，可选择 `图书/批量导入.csv` 与 `图书/书脊图.zip`。应先在目标地图中恢复同名点位（尤其是“书架点 4”）；目标平台须支持上述五列格式并具备可用的书脊图库服务。批量导入会新建图书和模板 ID，不会保留原 ID，重复导入可能产生重复记录。本次只生成文件，没有执行导入。
- CSV 使用带 BOM 的 UTF-8 编码，方便表格软件识别中文；JSON/YAML/README 使用 UTF-8。
- 数据库内的地图、标注点与图书在同一个只读、可重复读事务中导出；图像采用文件复制并核对哈希。本备份是地图与图书资料备份，不是完整系统/数据库备份。
